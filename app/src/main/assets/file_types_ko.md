# 파일 형식

### 문서

- PDF `.pdf`
- Word `.docx` `.docm` `.dotx` `.doc` `.dot`
- OpenDocument `.odt` `.ott` `.fodt`
- 서식 있는 텍스트 `.rtf`

### 스프레드시트

- Excel `.xlsx` `.xls` `.xlsm` `.xlsb` `.xltx`
- CSV `.csv`
- OpenDocument `.ods`

### 슬라이드

- PowerPoint `.pptx` `.ppsx` `.pptm` `.potx`

### 사진과 이미지

- `.jpg` `.jpeg` `.png` `.heic` `.heif` `.webp` `.gif` `.bmp` `.svg` `.avif` `.ico`

### 동영상

- `.mp4` `.m4v` `.mov` `.mkv` `.webm` `.3gp` `.3g2` `.avi` `.flv` `.m2ts` `.mts`
- 동영상으로 지정된 `.ts`

### 오디오

- `.mp3` `.m4a` `.aac` `.flac` `.wav` `.ogg` `.oga` `.opus` `.amr`

### Markdown

- `.md` `.markdown`

### 텍스트와 코드

- 텍스트 `.txt` `.log`
- 데이터와 설정 `.json` `.xml` `.yaml` `.yml` `.toml` `.ini` `.cfg` `.conf` `.properties`
- 코드 `.kt` `.java` `.py` `.js` `.ts` `.html` `.htm` `.css` `.sh` `.zsh` `.bash` `.c` `.cpp` `.h` `.hpp` `.rs` `.go` `.rb` `.php` `.sql` `.swift` `.dart` `.gradle` `.r` `.tex`
- 자막 `.srt` `.vtt`
- 재생 목록 `.m3u`
- 다운로드 정보 `.nfo`
- Verilog 및 VHDL `.v` `.vh` `.sv` `.svh` `.vhd` `.vhdl`
- Graphviz 그래프 `.gv` `.dot`

### 전자책

- DRM이 없는 EPUB `.epub`

### 압축 파일

- `.zip`

### 3D 모델

- STL `.stl`
